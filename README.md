# VCRUISE — лендінг круїзного агентства

Проєкт на Next.js 15 (App Router) + React + TypeScript + Tailwind CSS v4, що
відтворює наданий дизайн-макет: хедер, hero з пошуковою панеллю, найближчі
круїзи, "Життя на борту", популярні напрямки, форма підбору круїзу, пакетні
тури, блок "Про нас", CTA-секція та футер.

## Стек

- Next.js 15 (App Router, Turbopack)
- React 19 + TypeScript
- Tailwind CSS v4 (дизайн-токени через `@theme` у `app/globals.css`)
- lucide-react — іконки

## Фото

Усі зображення — стокові плейсхолдери з LoremFlickr, підібрані за ключовими
словами під тематику кожного блоку (круїзи, узбережжя, готелі тощо), щоб
верстку було зручно оцінити вже зараз. Перед запуском у продакшн замініть їх
на реальні фото клієнта:

- `data/cruises.ts` — картки найближчих круїзів
- `data/tours.ts` — картки пакетних турів
- `data/destinations.ts` — популярні напрямки
- `data/onboard.ts` — секція "Життя на борту"
- `components/Hero.tsx`, `components/CruiseFinder.tsx`,
  `components/AboutUs.tsx`, `components/CTASection.tsx` — точкові фото

Найпростіше — відредагувати виклики `stockPhoto(...)` (файл
`lib/stock-image.ts`) або одразу підставити прямі посилання/локальні файли з
`public/`.

## Адмін-панель

Панель керування: [http://localhost:3000/admin](http://localhost:3000/admin)

За замовчуванням: логін `admin`, пароль `vcruise2025`  
(змініть через `ADMIN_LOGIN` / `ADMIN_PASSWORD` у `.env`).

Розділи:

- **Дашборд** — заявки, круїзи, остання синхронізація
- **Заявки** — inbox форм зв’язку / бронювань (збереження в SQLite + Telegram)
- **Чат** — онлайн-віджет: діалоги в реальному часі, файли, заготовки, звуки
- **Контент** — тексти й фото блоків головної (hero, about, CTA тощо)
- **Синхронізація** — статус парсера круїзів і запуск оновлення
- **Налаштування** — бренд, контакти, SEO, увімкнення чату, Telegram

Онлайн-чат вмикається в **Налаштування → Чат**. Повідомлення дублюються в
адмінку через SSE + polling без перезавантаження сторінки.

**Інструкції** (кнопка в шапці адмінки) — інтерактивний тур по всіх розділах
(як у HOME HUB): підсвітка елементів, кроки з порадами. Автоматично
показується при першому вході; Esc або «Розберуся сам» завершує тур.

Дані CMS: `cms-data/vcruise.sqlite` (+ `cms-data/uploads/`).

## Структура

```
app/                 — сторінки App Router (layout, page, admin, api)
components/          — секції сайту + components/admin
data/                — статичні дані (тури, напрямки, класи)
lib/cms/             — SQLite CMS, сесії, sync
cms-data/            — SQLite + завантажені медіа (gitignore)
types/               — спільні TypeScript-типи
```
